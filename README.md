# Telecom Customer Churn Prediction

## Project Overview

This project predicts whether telecom customers will leave the service (churn) using machine learning techniques.

## Problem Statement

Customer churn is a major challenge for telecom companies. Predicting churn helps companies retain customers through targeted marketing strategies.

## Workflow

1. Data Cleaning
2. Exploratory Data Analysis
3. Feature Engineering
4. Model Training
5. Model Evaluation

## Technologies Used

* Python
* Pandas
* NumPy
* Scikit-learn
* Matplotlib
* Seaborn

## Machine Learning Models

* Logistic Regression
* Decision Tree
* Random Forest

## Outcome

The model identifies high-risk customers who are likely to churn.
